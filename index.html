Panduan Hosting Online di GitHub Pages & Auto-Upload Google Drive

Langkah 1 — Aktifkan Auto-Upload File & Logo ke Google Drive
  1. Buka Google Sheets Buku Induk Prodi TIK Anda, lalu klik menu Ekstensi (Extensions) > Apps Script.
  2. Hapus kode lama, lalu tempel (Paste) Kode Apps Script V11 yang baru saja disalin.
  3. Klik Terapkan (Deploy) > Kelola penerapan (Manage deployments) > klik ikon pensil (Edit) > pilih versi Versi baru (New version) > klik Terapkan (Deploy).
  4. Saat diminta izin akses Google Drive (`DriveApp`), klik Review Permissions > Allow. Mulai saat itu, setiap logo yang diunggah dan sertifikat yang diarsipkan otomatis tersimpan di folder Google Drive Prodi!
Langkah 2 — Publikasi Web Online Gratis di GitHub Pages
  1. Login ke github.com dan klik tombol + > New repository.
  2. Beri nama repositori, misalnya: sertifikat-tik-unpad, pilih Public, lalu klik Create repository.
  3. Klik uploading an existing file, seret file index.html ini ke halaman tersebut, lalu klik Commit changes.
  4. Buka tab Settings di repositori tersebut > pilih menu Pages di sisi kiri.
  5. Pada bagian Build and deployment > Branch, pilih main (folder / (root)) lalu klik Save.
  6. Tunggu 1–2 menit lalu refresh halaman Pages. Web Anda akan aktif secara online di alamat:
    https://username-anda.github.io/sertifikat-tik-unpad/
Catatan Keamanan & Portabilitas: Karena URL Web App Apps Script sudah tertanam di dalam index.html, siapa pun staf/admin Prodi TIK yang membuka link GitHub Pages Anda dapat langsung menerbitkan sertifikat, mengunggah logo ke Google Drive, dan mencatat arsip ke Google Sheets tanpa pengaturan ulang.
